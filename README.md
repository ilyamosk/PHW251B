Welcome to the official GitHub repo for the PHW251B Data Visualization course at the University of California, Berkeley!

##  Repository Organization

The course is organized into weeks. Most weeks have **Lab Modules** where you are going to be learning how to implement the theory from lectures into practice! This README file has a description of all the **Lab Modules** covered in the course to assist with your repository navigation.

---

## Week 1

### Lab Module 0 — Orientation (01_orientation.Rmd)

This Module orients you to how we use DataHub in PHW251B, We also introduce the concept of the RProject, the `here` package for orienting your working directory for reading in data, the `janitor` package for cleaning column names, and the `knitr` package and its tools to control rendering/knitting. Finally, we show you how to set custom themes, fonts, rainbow parentheses, function highlighting, automatic indentation, and other helpful settings via Global Options in your RStudio DataHub environment.

### Lab Module 1 — `dplyr` Basics (01_dplyr-basics.Rmd)

This module reviews the basics of the dplyr package, including reading data, mutating variables, and subsetting. The data management and cleaning skills shown in this video are essential prerequisites to creating visualizations with R. These videos will prepare you to complete Assignment #1, which is assigned in Week 3.

R files and datasets shown in videos will be available on DataHub, when the course officially begins on [UPDATE - Monday, August 25th]. 

Please note that we made some revisions to this module that are documented in the code and do not appear in the videos.

## Week 3

### Lab Module 1 — Summary Statistics (03_summary-stats.Rmd)

Module 1 covers summary statistics, which are an important part of data wrangling and the exploratory data analysis (EDA) process for deriving meaningful measures from your data. This is where we find insight into our data by examining continuous data for its center and spread and categorical/nominal data for its frequencies and occurrence. This lab module will go over common tools to investigate and derive summary statistics from datasets with EDA and data visualization in mind.

### Lab Module 2 — Bar Charts (03_bar-charts.Rmd)

Module 2 covers bar charts. In this module, we would like you to explore a dataset and create a bar chart of your choice (i.e., basic/regular, dodged, or stacked) and follow the principles of good graphical design. We recommend you use this as an opportunity to step out of your comfort zone and try creating a bar chart you haven't yet explored.

## Week 6

### Lab Module 1 — Line Plots and Scatterplots (05_strings-dates.Rmd)

In our proverbial toolkit of visualizations, scatterplots fill in the gap for displaying the relationship between two continuous numerical variables. These two variables are plotted on two axes and compared against one another. Common examples of relationships that are commonly plotted using scatterplots include height and weight, temperature and PM2.5, time series and mortality, a country's % of GDP invested into social services and healthcare, and so on. 

R files and datasets shown in the video will be available on DataHub.
